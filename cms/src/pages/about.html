Open source

A website builder you can own.

Doolox CMS is a free and open source website builder and content management system. It turns simple templates into complete static websites that you can host anywhere.

Doolox CMS is different from doolox.com: that is a service that builds and maintains websites for you, while Doolox CMS is the free, open source tool you run yourself.

Start from clean templates, edit your pages and content, then generate static HTML that runs on any host — no server, no subscription, no lock-in.
